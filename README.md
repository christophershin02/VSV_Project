# Vesicular Stomatitis Antibody Project

Project in collaboration with the Mayo Clinic. 

Most of the simulations were run in the ./Minimization directory. The main.py script created the antibody-glycoprotein complex and the main_analysis.py & main_analysis_res.py scripts ran calculations of the binding interface. The data generated was used to create figures which we sent to our collaborators at the Mayo Clinic.
